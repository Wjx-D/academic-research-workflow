# Nature Data — 数据可用性管理

基于 `Yuan1z0825/nature-skills` 的 `nature-data` 技能。

## 核心功能

1. **Data Availability Statement** 起草
2. **数据仓储方案**：选择合适的数据库
3. **数据集引用**：DataCite格式
4. **FAIR检查**：可发现、可访问、可互操作、可重用

## 数据分类

- 公开存储库数据
- 受控访问数据
- 论文内数据
- 重用公开数据
- 第三方受限数据
- 合理请求数据
- 不适用

## 相关技能

- `nature-writing` — 在方法部分描述数据
- `statistical-analysis` — 提供分析数据
