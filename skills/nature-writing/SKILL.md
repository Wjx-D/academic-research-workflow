# Nature Writing — 学术论文写作

基于 `Yuan1z0825/nature-skills` 的 `nature-writing` 技能。

## 核心功能

1. **多类型论文**：原创研究、方法学、假设驱动、算法、综述
2. **分章节起草**：摘要、引言、文献回顾、方法、实验、讨论、结论
3. **论证建构**：主张-证据链、逻辑流、反论点处理
4. **期刊适配**：Nature / Nature Communications / 通用期刊

## 工作流程

1. 论文类型与期刊确定
2. 核心论点提炼
3. 结构设计
4. 逐章起草
5. 逻辑一致性检查

## 相关技能

- `nature-polishing` — 润色已起草文本
- `nature-reviewer` — 预审稿评审
- `nature-figure` — 图表制作配合
- `deep-research` — 提供研究基础
