# Scientific Brainstorming — 科研选题与头脑风暴

将模糊的研究兴趣转化为可执行、可发表的研究选题。

## 工作流程

### Phase 1: 兴趣澄清 (Interest Clarification)

通过结构化对话澄清研究兴趣：

1. **领域定位**：你的研究属于哪个学科/子领域？
2. **问题类型**：理论问题 / 实证问题 / 方法创新 / 应用探索？
3. **动机溯源**：是什么触发你对这个问题的兴趣？（临床观察、文献缺口、理论矛盾）
4. **约束条件**：时间、资源、数据获取、伦理限制
5. **期望产出**：期刊论文 / 学位论文 / 会议报告 / 基金申请？

### Phase 2: 文献缺口映射 (Gap Mapping)

基于已有文献识别研究缺口：

```
文献缺口分析框架：
├── 理论缺口
│   ├── 现有理论无法解释的现象
│   ├── 理论之间的矛盾与冲突
│   └── 理论在特定情境下的适用性
├── 方法缺口
│   ├── 现有方法的局限性
│   ├── 新方法的应用潜力
│   └── 跨学科方法的引入
├── 实证缺口
│   ├── 特定人群/情境的缺失
│   ├── 纵向/因果关系的缺乏
│   └── 效应机制的未明
└── 应用缺口
    ├── 理论到实践的转化
    ├── 干预方案的开发与验证
    └── 政策建议的依据
```

### Phase 3: FINER 可行性评估

对候选选题进行 FINER 评估：

| 维度 | 问题 | 评估标准 |
|------|------|----------|
| **F**easible | 在现有资源下可完成吗？ | 样本量可及、时间合理、经费可行 |
| **I**nteresting | 对你和领域都有趣吗？ | 个人热情 + 领域关注度 |
| **N**ovel | 有创新点吗？ | 理论/方法/实证/应用创新 |
| **E**thical | 符合伦理规范吗？ | 伦理审批可获取、无重大风险 |
| **R**elevant | 对领域有实际价值吗？ | 理论贡献 + 实践意义 |

### Phase 4: 选题精炼与验证

将初步选题精炼为研究问题：

1. **PICOS 框架**（适用于临床研究）：
   - P (Population): 研究对象
   - I (Intervention): 干预措施
   - C (Comparison): 对照条件
   - O (Outcome): 结局指标
   - S (Setting): 研究场景

2. **研究问题表述检查清单**：
   - [ ] 问题具体且边界清晰
   - [ ] 可通过经验数据回答
   - [ ] 非是/否问题，而是解释/探索/比较
   - [ ] 变量关系可操作化
   - [ ] 预期贡献明确

### Phase 5: 多选题对比决策

当存在多个候选选题时：

| 评估维度 | 权重 | 选题A | 选题B | 选题C |
|----------|------|-------|-------|-------|
| 创新性 | 25% | 评分1-5 | 评分1-5 | 评分1-5 |
| 可行性 | 25% | 评分1-5 | 评分1-5 | 评分1-5 |
| 个人热情 | 20% | 评分1-5 | 评分1-5 | 评分1-5 |
| 领域价值 | 20% | 评分1-5 | 评分1-5 | 评分1-5 |
| 时间合理性 | 10% | 评分1-5 | 评分1-5 | 评分1-5 |
| **加权总分** | 100% | | | |

## 反模式

| 反模式 | 错误原因 | 正确做法 |
|--------|----------|----------|
| 选题过大 | 无法在有限时间内完成 | 缩小范围，聚焦特定情境/人群 |
| 选题过新 | 缺乏文献支撑 | 确保有理论基础和方法论参考 |
| 追逐热点 | 缺乏个人独特贡献 | 结合个人专长和独特视角 |
| 忽视可行性 | 数据/样本无法获取 | 提前确认资源可及性 |
| 问题过于宽泛 | 无法聚焦研究设计 | 使用PICOS框架精炼 |
