# Literature Review — 系统性文献综述与Meta分析

## 工作流程

### Phase 1: 综述协议设计 (Protocol Design)

在开始检索前，先设计综述协议：

1. **综述类型选择**：
   - 系统综述（Systematic Review）
   - Meta分析（Meta-analysis）
   - 范围综述（Scoping Review）
   - 叙述性综述（Narrative Review）
   - 理论综述（Theoretical Review）

2. **研究问题定义**（使用 PICO/PECO/SPIDER 框架）：
   ```
   PICO: Population, Intervention, Comparison, Outcome
   PECO: Population, Exposure, Comparison, Outcome
   SPIDER: Sample, Phenomenon, Design, Evaluation, Research type
   ```

3. **纳入/排除标准**（提前定义）：
   - 语言、发表年份、研究设计、人群特征
   - 结局指标、地域限制、数据库范围

4. **检索策略**：
   - 数据库选择（PubMed/MEDLINE, Cochrane, Web of Science, Scopus, CNKI, Wanfang）
   - 关键词/主题词（MeSH, Emtree, 自由词）
   - 布尔运算符（AND, OR, NOT）
   - 检索式记录

5. **注册协议**：
   - PROSPERO（系统综述）
   - OSF（开放科学框架）

### Phase 2: 文献检索 (Search)

执行系统性检索：

```
检索流程：
1. 在选定数据库执行检索式
2. 导出检索结果（标题、摘要、关键词）
3. 记录各数据库检索结果数量
4. 合并去重
5. 记录检索日期和版本
```

### Phase 3: 筛选与评估 (Screening & Assessment)

```
PRISMA 2020 流程：
├── 识别 (Identification)
│   ├── 数据库检索 → n=____
│   ├── 其他来源 → n=____
│   └── 去重后 → n=____
├── 筛选 (Screening)
│   ├── 标题/摘要筛选 → 纳入 n=____, 排除 n=____（附原因）
│   └── 全文筛选 → 纳入 n=____, 排除 n=____（附原因）
└── 纳入 (Included)
    └── 最终纳入研究 → n=____
```

**筛选执行规则**：
- 至少两名研究者独立筛选
- 使用Rayyan或Covidence等工具
- 记录排除原因
- 计算筛选一致性（Kappa值）

**质量评估工具**：

| 研究设计 | 评估工具 |
|----------|----------|
| RCT | Cochrane RoB 2 |
| 非随机研究 | ROBINS-I |
| 观察性研究 | Newcastle-Ottawa Scale |
| 诊断试验 | QUADAS-2 |
| 质性研究 | CASP / JBI |
| 预后研究 | PROBAST |

### Phase 4: 数据提取 (Data Extraction)

设计数据提取表：

```markdown
| 字段 | 说明 |
|------|------|
| 第一作者/年份 | 文献标识 |
| 国家/地区 | 研究场景 |
| 研究设计 | RCT/队列/病例对照等 |
| 样本量 | 总样本量/各组样本量 |
| 人群特征 | 年龄、性别、疾病状态 |
| 干预/暴露 | 详细描述 |
| 对照 | 对照条件描述 |
| 结局指标 | 主要和次要结局 |
| 效应量 | 原始数据或汇总统计 |
| 质量评分 | RoB/NOS评分 |
```

### Phase 5: 统计合成 (Statistical Synthesis)

**Meta分析步骤**：

1. **效应量选择**：
   - 连续变量：SMD（标准化均数差）, MD（均数差）, WMD
   - 二分类变量：RR（相对风险）, OR（比值比）, RD（风险差）
   - 相关性：r, Fisher's z
   - 生存数据：HR（风险比）

2. **合并模型**：
   - 固定效应模型（Fixed-effect）：研究间差异仅来自抽样误差
   - 随机效应模型（Random-effects）：研究间存在真实差异

3. **异质性评估**：
   ```
   I² 解释：
   - 0-40%：可能不重要
   - 30-60%：中等
   - 50-90%： substantial
   - 75-100%： considerable
   
   Q统计量（卡方检验）p < 0.10 提示显著异质性
   ```

4. **亚组分析**：
   - 按研究设计、人群特征、干预类型、质量评分分组

5. **Meta回归**：
   - 探索异质性来源
   - 至少需要10项研究

6. **发表偏倚**：
   - 漏斗图（Funnel Plot）：视觉检查
   - Egger检验：回归法（至少10项研究）
   - 剪补法（Trim and Fill）
   - 选择模型

7. **敏感性分析**：
   - 逐一排除法
   - 按质量分层
   - 不同模型比较

### Phase 6: 结果报告 (Reporting)

**PRISMA 2020 检查清单**：

报告必须包含：
- [ ] 标题（含"系统综述"和/或"Meta分析"）
- [ ] 结构化摘要
- [ ] 背景和原理
- [ ] 纳入标准
- [ ] 信息来源和检索策略
- [ ] 筛选流程（PRISMA流程图）
- [ ] 纳入研究特征表
- [ ] 各研究风险偏倚
- [ ] 单个研究结果
- [ ] 合成结果（森林图）
- [ ] 报告限制
- [ ] 结论和证据确定性（GRADE）

**GRADE 证据分级**：

| 确定性 | 含义 | 表达 |
|--------|------|------|
| 高 | 非常确信效应估计值接近真实值 | "我们非常确信..." |
| 中 | 对效应估计值有中等信心 | "我们有中等把握..." |
| 低 | 对效应估计值的确信有限 | "我们对...的信心有限" |
| 极低 | 对效应估计值几乎没有信心 | "我们对...非常不确定" |

降级因素：研究局限性、不一致性、间接性、不精确性、发表偏倚
升级因素：大效应量、剂量-反应关系、残余混杂偏向无效假设

## 输出格式

### 森林图（Forest Plot）
```
研究          | 效应量 [95% CI]        | 权重  |
--------------|------------------------|-------|
Author 2020   | ◆ 0.50 [0.20, 0.80]   | 15%  |
Author 2021   | ◆ 0.60 [0.30, 0.90]   | 20%  |
Author 2022   | ◆ 0.45 [0.10, 0.80]   | 25%  |
...           |                        |      |
--------------|------------------------|-------|
合并效应量     | ◆ 0.52 [0.30, 0.74]   | 100% |
```

### 结果表格模板
```markdown
| 结局指标 | 研究数 | 样本量 | 效应量 [95% CI] | I² | P值 | 确定性 |
|----------|--------|--------|-----------------|----|----|--------|
| 主要结局 | n | N | OR 0.52 [0.30, 0.90] | 45% | 0.02 | 中等 |
| 次要结局1 | n | N | MD -2.5 [-4.0, -1.0] | 30% | 0.001 | 高 |
```

## 反模式

| 反模式 | 错误原因 | 正确做法 |
|--------|----------|----------|
| 检索不全 | 遗漏关键数据库或关键词 | 系统检索多个数据库，使用MeSH词 |
| 选择性纳入 | cherry-picking 支持性研究 | 预先定义纳入标准，独立双筛 |
| 忽略异质性 | 强行合并不可比的研究 | 当I² > 50%时考虑亚组分析 |
| 忽视质量 | 纳入低质量研究 | 进行质量评估和敏感性分析 |
| 忽视发表偏倚 | 只纳入阳性结果 | 使用漏斗图和Egger检验 |
| 过度解读 | 超出证据确定性下结论 | 使用GRADE框架表达确定性 |
