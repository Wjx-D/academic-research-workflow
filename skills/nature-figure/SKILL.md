# Nature Figure — 科研绘图

基于 `Yuan1z0825/nature-skills` 的 `nature-figure` 技能。

## 核心功能

1. **双后端支持**：Python (matplotlib/seaborn) / R (ggplot2/patchwork)
2. **期刊标准**：Nature及高影响力期刊视觉规范
3. **输出格式**：SVG (可编辑), PDF, TIFF (300dpi+)
4. **图型覆盖**：散点图、线图、柱状图、箱线图、热图、森林图、多面板组合图

## 工作流程

1. 明确图表核心结论
2. 选择图型和配色
3. 绘制并调整
4. 导出期刊要求格式
5. QA检查

## 设计原则

- 图表服务于科学逻辑
- 克制配色，优先色盲友好
- 统计信息完整标注
- 高分辨率导出

## 相关技能

- `statistical-analysis` — 提供统计数据
- `literature-review` — 森林图等Meta分析图表
- `nature-writing` — 图表与正文配合
