# Nature Polishing — 学术文本润色

基于 `Yuan1z0825/nature-skills` 的 `nature-polishing` 技能。

## 核心功能

1. **风格转换**：润色为Nature期刊英文风格
2. **语言处理**：中文学术草稿翻译为英文
3. **结构优化**：段落逻辑、句子流畅度、学术表达
4. **排版修复**：LaTeX布局问题（浮动体、分页、多面板图）

## 工作维度

- paper_type: research / methods / hypothesis / algorithmic / review
- section: abstract / intro / results / discussion / methods
- language: en / zh-to-en
- journal: nature / nat-comms / generic
