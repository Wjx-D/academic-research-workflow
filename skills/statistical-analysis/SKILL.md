# Statistical Analysis — 医学统计分析与研究设计

## 工作流程

### Phase 1: 研究设计选择 (Study Design Selection)

根据研究问题选择最合适的设计：

```
研究问题类型 → 研究设计
├── 治疗效果/因果关系
│   ├── 随机对照试验 (RCT) — 金标准
│   ├── 准实验设计 (前后对照、间断时间序列)
│   └── 观察性研究 (队列、病例对照)
├── 关联/风险因素
│   ├── 前瞻性队列研究
│   ├── 横断面研究
│   └── 病例对照研究
├── 诊断准确性
│   └── 诊断试验 (与金标准对比)
├── 预后因素
│   └── 队列研究 (生存分析)
├── 现象描述/体验
│   └── 质性研究 (现象学、扎根理论、民族志)
└── 现有证据综合
    ├── 系统综述 + Meta分析
    └── 范围综述
```

### Phase 2: 变量操作化 (Variable Operationalization)

```
变量类型分类：
├── 自变量 (Independent/Predictor)
│   ├── 二分类 (治疗/对照)
│   ├── 多分类 (干预A/B/C)
│   └── 连续 (剂量、评分)
├── 因变量 (Outcome/Dependent)
│   ├── 连续 (血压、BMI、量表得分)
│   ├── 二分类 (发病/未发病)
│   ├── 有序分类 (轻/中/重度)
│   ├── 计数 (事件次数)
│   └── 生存时间 (时间-to-事件)
├── 协变量 (Covariate/Confounder)
│   ├── 人口学特征 (年龄、性别、教育)
│   ├── 临床特征 (病程、合并症)
│   └── 其他潜在混杂
└── 中介/调节变量
    ├── 中介变量 (机制解释)
    └── 调节变量 (效应修饰)
```

### Phase 3: 样本量估算 (Sample Size Estimation)

**常见设计样本量公式**：

| 设计类型 | 公式/方法 | 关键参数 |
|----------|-----------|----------|
| 两组均数比较 | n = 2(Z₁₋α/₂ + Z₁₋β)²σ²/δ² | α, β, σ, δ(效应量) |
| 两组率比较 | 基于正态近似法 | p₁, p₂, α, β |
| 诊断试验 | 灵敏度/特异度估计 | Se, Sp, 容许误差d |
| 相关分析 | n = (Z₁₋α/₂/Zᵣ)² + 3 | 预期相关系数r |
| 回归分析 | EPV ≥ 10 (Events Per Variable) | 事件数/变量数 ≥ 10 |
| 生存分析 | Log-rank检验公式 | HR, α, β, 入组/随访时间 |

**样本量计算步骤**：
1. 确定主要结局指标
2. 选择统计检验方法
3. 设定参数：α(通常0.05), β(通常0.20, 即效能80%)
4. 估计效应量（基于文献或临床意义）
5. 考虑脱落率（通常10-20%）
6. 使用软件验证：G*Power, PASS, R, Stata, SAS

### Phase 4: 描述性统计 (Descriptive Statistics)

```
数据类型 → 描述指标 → 图表
├── 连续变量（正态）
│   ├── 均数 ± 标准差 (Mean ± SD)
│   └── 直方图、箱线图
├── 连续变量（偏态）
│   ├── 中位数 (四分位数) [M (P25, P75)]
│   └── 直方图、箱线图
├── 分类变量
│   ├── 频数 (百分比) [n (%)]
│   └── 条形图、饼图
└── 时间-事件数据
    ├── 中位生存时间 (95% CI)
    └── Kaplan-Meier曲线
```

### Phase 5: 统计检验选择 (Test Selection)

**两组比较**：

| 结局类型 | 独立两组 | 配对设计 | 多组比较 |
|----------|----------|----------|----------|
| 连续(正态) | 独立t检验 | 配对t检验 | 单因素ANOVA |
| 连续(偏态) | Mann-Whitney U | Wilcoxon符号秩 | Kruskal-Wallis H |
| 二分类 | 卡方检验/Fisher精确 | McNemar检验 | 卡方检验 |
| 有序分类 | Mann-Whitney U | Wilcoxon符号秩 | Kruskal-Wallis H |

**关联分析**：

| 变量类型 | 分析方法 |
|----------|----------|
| 两连续变量 | Pearson相关 / Spearman相关 |
| 连续 + 二分类 | 点二列相关 / 独立t检验 |
| 两有序变量 | Spearman相关 / Kendall's tau |
| 多分类变量 | 卡方检验 / Cramér's V |

**回归分析**：

| 结局类型 | 回归模型 | 应用 |
|----------|----------|------|
| 连续(正态) | 线性回归 | 影响因素分析、预测 |
| 二分类 | Logistic回归 | 危险因素、预测模型 |
| 有序分类 | 有序Logistic回归 | 等级结局 |
| 计数 | Poisson/负二项回归 | 事件率分析 |
| 生存时间 | Cox比例风险回归 | 预后因素 |
| 纵向连续 | 线性混合效应模型 | 重复测量 |
| 纵向二分类 | 广义估计方程(GEE) | 重复测量 |

### Phase 6: 统计报告规范 (Reporting Standards)

**关键报告规范**：

| 规范 | 适用研究 | 核心要素 |
|------|----------|----------|
| CONSORT | RCT | 随机化、流程图、基线表、意向性分析 |
| STROBE | 观察性研究 | 设计说明、偏倚控制、敏感性分析 |
| CARE | 病例报告 | 时间线、诊疗过程、文献回顾 |
| TRIPOD | 预测模型 | 模型开发/验证、性能指标、校准 |
| PRISMA | 系统综述 | 检索、筛选、质量、合成 |
| CHEERS | 卫生经济学 | 成本测算、效果指标、视角 |
| COREQ | 质性研究 | 研究者角色、访谈过程、分析 |

**统计报告必备元素**：

```markdown
1. 描述性统计
   - 基线特征表 (Table 1)
   - 缺失数据处理说明

2. 效应估计
   - 点估计 + 95%置信区间
   - P值（精确到3位小数）

3. 模型报告
   - 调整变量说明
   - 模型假设检验
   - 交互作用检验

4. 敏感性分析
   - 缺失数据多重填补
   - 异常值影响
   - 不同模型比较

5. 补充材料
   - 原始数据（如适用）
   - 分析代码
   - 伦理审批号
```

## 效应量参考标准

| 效应量指标 | 小效应 | 中效应 | 大效应 |
|------------|--------|--------|--------|
| Cohen's d | 0.2 | 0.5 | 0.8 |
| 相关系数 r | 0.1 | 0.3 | 0.5 |
| R² | 0.02 | 0.13 | 0.26 |
| OR/RR | 1.5 | 2.5 | 4.0 |
| Cramér's V | 0.1 | 0.3 | 0.5 |

## 统计假设检验清单

分析前检查：
- [ ] 正态性检验（Shapiro-Wilk / Kolmogorov-Smirnov）
- [ ] 方差齐性（Levene检验 / Bartlett检验）
- [ ] 异常值识别
- [ ] 多重共线性（VIF < 10）
- [ ] 样本独立性

## 反模式

| 反模式 | 错误原因 | 正确做法 |
|--------|----------|----------|
| P值崇拜 | 仅看P值忽略效应量和CI | 报告效应量 + 95% CI + P值 |
| 多重比较不做校正 | 假阳性膨胀 | Bonferroni, FDR, holm |
| 忽视检验前提 | 数据不满足假设 | 非参数检验或数据变换 |
| 事后检验 | 未预设比较 | 预设主要/次要结局 |
| 过度拟合 | 变量数/样本量比过高 | EPV ≥ 10，交叉验证 |
| 忽视混杂 | 观察性研究不做调整 | 识别并控制混杂因素 |
| 亚组分析过多 | 假阳性 | 预设亚组，多重比较校正 |
